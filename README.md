## QUIZFLOW - FRONTEND 

Voici le *workflow* qui definira notre maniere de travailler le frontEnd de cette application :

- faire un  _git checkout dev_ directement apres avoir cloner le projet.
- TRES IMPORTANT : CREER SA BRANCHE AVANT DE REALISER TOUTES TACHES !!!
ceci se fait a travers la commande :  _git checkout -b feature/nom-de-votre-branche_ ou _nom-de-votre-branche_ est le nom que vous meme aurez attribuer a la branche apres avoir executer _git checkout dev_

- VOUS NE TRAVAILLEREZ AINSI JAMAIS SUR LES BRANCHES 'main' ou 'dev' !!!

- apres terminaison de votre fonctionnalite, faite un _git push -u origin_ depuis votre branche de travail 

#### Les fonctionnalites a developper vous seront assigner sous formes de issues depuis Github
